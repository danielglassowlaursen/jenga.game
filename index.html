🦁 Animal Jenga 🐘

Blocks Removed: 0
Click on a block to pull it!

🎮 How to Play:

  • Click on a block to pull it from the tower
  • Each animal block has a special effect!
  • Try to remove as many blocks as possible
  • Don't let the tower fall!

🐾 Animal Powers:

  • 🐘 Elephant: Heavy shake!
  • 🐱 Cat: Sneaky - smooth removal
  • 🐉 Dragon: Fire blast!
  • 💨 Cow: Fart power - blocks wobble!
  • ⚡ Tiger: Lightning strike!
  • 🐸 Frog: Bouncy blocks!
  • 🦅 Eagle: Wind gust!
  • 🐢 Turtle: Slow and steady
