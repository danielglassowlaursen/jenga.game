# Animal Jenga Game

A fun 3D Jenga game where each block is themed as an animal with special powers!

## Features

- **3D Graphics**: Built with Three.js for a realistic 3D Jenga tower
- **8 Animal Types**: Each with unique special effects
- **Interactive Gameplay**: Click blocks to pull them from the tower
- **Special Effects**: Experience fire blasts, lightning strikes, farts, and more!
- **Physics Simulation**: Realistic block movements and gravity

## Animal Powers

| Animal | Emoji | Special Effect |
|--------|-------|----------------|
| Elephant | 🐘 | Heavy shake - makes all blocks wobble |
| Cat | 🐱 | Sneaky - smooth removal with no side effects |
| Dragon | 🐉 | Fire blast - pushes nearby blocks away |
| Cow | 💨 | Fart power - makes blocks bounce and wobble |
| Tiger | ⚡ | Lightning strike - random block gets zapped |
| Frog | 🐸 | Bouncy - all blocks jump up |
| Eagle | 🦅 | Wind gust - blows blocks in a direction |
| Turtle | 🐢 | Slow and steady - calm removal |

## How to Play

1. Open `index.html` in a modern web browser
2. Click on any block in the tower to pull it
3. Watch the special effect activate!
4. Try to remove as many blocks as possible without toppling the tower
5. Click "New Game" to reset and play again

## Technical Details

- **Framework**: Vanilla JavaScript with Three.js
- **3D Rendering**: WebGL via Three.js
- **No Build Required**: Just open index.html in a browser!

## Browser Compatibility

Works best in modern browsers with WebGL support:
- Chrome/Edge (recommended)
- Firefox
- Safari
